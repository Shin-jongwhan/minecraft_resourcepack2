Meowwtail Chat Bot

방송 채널 beast tail 의 마인크래프트 시청자 참여 서버 알림 봇이에요.

채널 주인 계정 하나로만 쓰이며, 방송 실시간 채팅에 구독 감사 · 서버 안내 같은 알림 글만 씁니다.

English

Meowwtail Chat Bot is a notification bot for the Minecraft community server of the beast tail live stream channel. It is used only by the channel owner's account and only posts notices (such as subscriber thank-you messages and server information) to the channel's own live chat.
